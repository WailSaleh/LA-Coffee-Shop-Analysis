# ☕ Coffee Shop Market Analysis

> A business analysis project evaluating the Los Angeles coffee shop market to support investment decisions, location planning, and long-term business growth using Python and data visualization.

---

# 📖 Project Overview

Before launching a new business, understanding the competitive landscape and market conditions is essential. This project analyzes the Los Angeles food and beverage industry to evaluate whether opening a coffee shop with robot waiters represents a sustainable business opportunity.

Using publicly available restaurant data, the analysis explores market composition, seating capacity, chain versus independent businesses, and geographic distribution to generate actionable recommendations for investors and business stakeholders.

---

# 📂 Dataset

The analysis uses open-source restaurant data containing information such as:

- Establishment Name
- Business Type
- Chain vs Independent Business
- Address
- Seating Capacity

> **Note:** The dataset included in this repository is provided for educational and portfolio purposes.

The objectives of this project were to:
